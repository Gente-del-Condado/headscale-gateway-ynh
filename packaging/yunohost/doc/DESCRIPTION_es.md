Headscale Gateway permite acceder por HTTPS a aplicaciones y servicios de tu
servidor o red local mediante una red Headscale existente. Integra un nodo VPN,
proxy inverso, gestión de DNS y certificados, opciones de acceso, perfiles de
configuración y copias cifradas desde un panel web.

El paquete integra el acceso administrativo con el portal de YunoHost y admite
varias instancias, actualizaciones, cambios de URL, copias y restauración.
No abre un nuevo puerto público de entrada. Necesita un servidor Headscale de
coordinación existente. El dominio HTTPS del portal y el dominio privado del
Gateway se configuran por separado.

El código propio se publica bajo AGPL-3.0-only. El paquete público incluye los
fuentes de compilación completos del motor y sus dependencias Go en
`payload/source.tar.gz`, con instrucciones, sumas y avisos de terceros.
